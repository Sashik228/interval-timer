# Інтервальний таймер

Веб-застосунок (PWA): інтервальні таймери зі звуком і розклад тренувань.

- **Моє тренування**: 5 с підготовки, далі 3 кола, кожне з двох блоків по 3 × 30 с роботи з перервами по 5 с. Після першого блоку 30 с відпочинку, після другого 60 с.
- Створення й редагування власних таймерів (підготовка, кола, блоки, підходи, перерви).
- Розклад по днях тижня з нагадуваннями через календар телефона (.ics або Google Календар).
- Працює офлайн, можна встановити на головний екран.

Дані зберігаються лише в браузері на пристрої.
